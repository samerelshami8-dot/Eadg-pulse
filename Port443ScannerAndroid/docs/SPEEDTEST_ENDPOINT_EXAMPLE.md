# نمونه endpoint برای تست سرعت

برای اینکه تست دانلود/آپلود دقیق باشد، بهتر است روی دامنه‌ای که مالک آن هستید یک فایل تست قرار دهید.

## دانلود

یک فایل مثلا 10MB روی سایت خودتان بگذارید:

```text
https://example.com/speedtest.bin
```

بعد در اپ وارد کنید:

```text
Host: example.com
Download Path: /speedtest.bin
Download Size: 2048 یا 4096 KB
```

## آپلود

آپلود فقط وقتی دقیق است که سرور شما یک endpoint برای دریافت POST داشته باشد؛ مثلا:

```text
https://example.com/upload
```

اگر endpoint ندارید، تست آپلود را خاموش بگذارید؛ چون خیلی از سرورها درخواست POST به مسیرهای معمولی را رد می‌کنند.

## نکته CDN

اگر می‌خواهید IPهای CDN را تست کنید، Host باید همان دامنه‌ای باشد که روی CDN تنظیم شده و اجازه تست آن را دارید. اپ به IP وصل می‌شود ولی با Host/SNI دامنه شما درخواست می‌فرستد.
